# JARVIS V2 — Assistente Inteligente

Versão 2 do projeto JARVIS, focada em:
- Dashboard futurista
- Chat com o assistente
- Módulos de sistema
- Memória local
- Automação permitida com confirmação
- Monitoramento básico do ambiente
- Arquitetura preparada para integração com APIs de IA

## Rodar
```bash
pip install -r requirements.txt
python run.py
```
Depois abra http://127.0.0.1:8000

## Segurança
A V2 não executa ações perigosas, invasivas ou não autorizadas. Ações externas devem exigir permissão/confirmacão.
